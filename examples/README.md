# Example projects

Projects to open in the desktop app (Home › **Open project…**). Each is a portable project
document: problem, method and notes, no results; runs are written next to the file, in
`result_<project name>/`.

| Project | What it shows |
| :-- | :-- |
| [`gui-cantilever/project.top`](gui-cantilever/project.top) | A custom 2-D cantilever drawn in the Problem editor. |
| [`gui-spatial/project.top`](gui-spatial/project.top) | Problem objects placed in the spatial editor. |
| [`drone-arm/drone-arm.top`](drone-arm/drone-arm.top) | A 200 × 85 mm drone arm bracket: bolted at two holes, loaded at eight motor holes in two load cases. |
| [`drone-arm/drone-arm-camera-view.top`](drone-arm/drone-arm-camera-view.top) | The drone arm with an area that must stay empty for a camera's view. |
| [`drone-arm/drone-arm-point-loads.top`](drone-arm/drone-arm-point-loads.top) | The drone arm's layout with point supports and point loads instead of holes and rings. |

The drone arm was a preset before 0.3.0; it is an application project, not a benchmark.
