Research: Convergence-triggered beta

Question
What does Convergence-triggered beta compute, and which part of its research claim can be reproduced?

Setup
Domain: 60 x 20 mm plate, 1 element per mm (60 x 20 elements).
Supports: left edge fixed in x; point (60, 0) fixed in y.
Loads at (0, 20); force 1 towards -y (down).
Material: Young's modulus 1 for solid, 1e-09 for void, Poisson ratio 0.3.
Volume budget: at most 50% of the domain may be material.
Objective: minimise Compliance (default settings).
Method: q4+mma with move 0.1; stops when the design changes by less than 0.01, at most 450 iterations.
Design variables: Element densities (default settings); material law: SIMP (power law) (default settings).
Filters, in order: Density filter (rmin 2.4); then Heaviside projection (beta 1, beta_max 128).
Continuation: When the design settles on filters[1].beta (start 1, end 128, factor 2, change_below 0.03, settle 1, min_every 10, max_every 50).
GUI Run is an optimization companion with the setup above; it does not launch the transfer-curve experiment. Figure settings: start 1, end 128, factor 2, change_below 0.03, settle 1, min_every 10, max_every 50; the reproduction command saves the diagnostic field or curve with all parameters.

How the function computes
Plot actual schedule values at completed-iteration boundaries. Compare to an independent clock/event simulation.

Mathematics

Increase after a sufficiently settled design or the maximum interval; minimum level duration is enforced.

Symbols and units
beta: current projection sharpness; beta-plus: next level. The event uses reported design change, a consecutive-settled count, minimum level duration and maximum-duration fallback; all settings are recorded. Superscript T denotes transpose where used.

Research target
Convergence-triggered continuation described in section 4; exact design history unavailable.

What is compared
The report separates independent numerical checks, equation/curve agreement, paper-visual comparison and unresolved reproduction. Diagnostic success alone never sets a paper match.

Limitations
The synthetic change signal and minimum-duration guard are declared Toporia choices. The source paper's actual observed design history is not reconstructed.
