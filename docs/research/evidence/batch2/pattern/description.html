Research: Repeated layout pattern

Question
What does Repeated layout pattern compute, and which part of its research claim can be reproduced?

Setup
Figure settings: {'type': 'pattern', 'nx': 3, 'ny': 2}. The diagnostic field/curve and all parameters are saved by the reproduction command. GUI Run is an optimization companion on the half-MBB beam (60 by 20 domain; mesh resolution 1.0; maximum 200 steps; volume budget 0.5); it does not launch the transfer-curve experiment.

How the function computes
Show six identical repeated cells and verify periodic equality and the exact adjoint.

Mathematics

All repetitions share the averaged local-cell value; mesh counts must divide exactly.

Symbols and units
c/d: repetition-cell indices; i: position inside a cell; nc: number of repetitions; P: folding-average-and-repeat operator. Density is dimensionless. Superscript T denotes transpose where used.

Research target
Almeida et al. layout-pattern restrictions; exact paper geometry/panel pending.

What is compared
The report separates independent numerical checks, equation/curve agreement, paper-visual comparison and unresolved reproduction. Diagnostic success alone never sets a paper match.

Limitations
Identical cells alone do not reproduce the paper's optimized structure; supports and loads need not repeat.

Reproduce
python -m experiments.research_batch2 --case pattern
