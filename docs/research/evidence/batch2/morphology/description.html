Research: Morphology: four operations

Question
What does Morphology: four operations compute, and which part of its research claim can be reproduced?

Setup
Figure settings: {'type': 'morphology', 'mode': 'open', 'beta': 32.0, 'rmin': 2.4}. The diagnostic field/curve and all parameters are saved by the reproduction command. GUI Run is an optimization companion on the half-MBB beam (60 by 20 domain; mesh resolution 1.0; maximum 200 steps; volume budget 0.5); it does not launch the transfer-curve experiment.

How the function computes
Apply erosion, dilation, opening and closing to the same controlled binary pattern; compare with hard morphological limits.

Mathematics

Normalized weights sum to one; shifted exponentials avoid overflow.

Smooth erosion is the soft minimum.

Opening removes thin solid details; closing fills thin void details.

Symbols and units
x: input density; D/E: smooth dilation/erosion; O/C: opening/closing; beta: sharpness; H: distance weights; w: normalized weights. Indices i/j refer to output/input cells. Superscript T denotes transpose where used.

Research target
Sigmund (2007), Figure 3, basic morphology operations; equations (18)-(21).

What is compared
The report separates independent numerical checks, equation/curve agreement, paper-visual comparison and unresolved reproduction. Diagnostic success alone never sets a paper match.

Limitations
The paper uses a five-cell structuring element and uniform weights for its illustrative binary example. Toporia uses cone weights and finite sharpness; the recreated pattern is not the original bitmap. Opening/closing are not generally exactly volume preserving on arbitrary fields.
