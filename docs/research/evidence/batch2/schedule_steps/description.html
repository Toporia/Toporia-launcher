Research: Equal-step continuation

Question
What does Equal-step continuation compute, and which part of its research claim can be reproduced?

Setup
Domain: 60 x 20 mm plate, 1 element per mm (60 x 20 elements).
Supports: left edge fixed in x; point (60, 0) fixed in y.
Loads at (0, 20); force 1 towards -y (down).
Material: Young's modulus 1 for solid, 1e-09 for void, Poisson ratio 0.3.
Volume budget: at most 50% of the domain may be material.
Objective: minimise Compliance (default settings).
Method: q4+oc; stops when the design changes by less than 0.01, at most 300 iterations.
Design variables: Element densities (default settings); material law: SIMP (power law) (default settings).
Filters, in order: Density filter (rmin 2.4).
Continuation: Equal steps on interpolation.penal (start 1, end 3, step 0.5, every 20).
GUI Run is an optimization companion with the setup above; it does not launch the transfer-curve experiment. Figure settings: start 1, end 3, step 0.5, every 20; the reproduction command saves the diagnostic field or curve with all parameters.

How the function computes
Plot actual schedule values at completed-iteration boundaries. Compare to an independent clock/event simulation.

Mathematics

k counts completed iterations; a value is set before the next step.

Symbols and units
k: completed iterations; p0/pmax: starting/final penalty; Delta p: increment; n: steps per level; floor: integer part. Superscript T denotes transpose where used.

Research target
General SIMP continuation; no source figure for this exact clock.

What is compared
The report separates independent numerical checks, equation/curve agreement, paper-visual comparison and unresolved reproduction. Diagnostic success alone never sets a paper match.

Limitations
The increment and interval are Toporia demonstration settings, not a reproduced research trajectory.
