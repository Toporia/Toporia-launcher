Research: Linear parameter ramp

Question
What does Linear parameter ramp compute, and which part of its research claim can be reproduced?

Setup
Figure settings: {'type': 'linear', 'start': 1.0, 'end': 3.0, 'after': 20, 'over': 80}. The diagnostic field/curve and all parameters are saved by the reproduction command. GUI Run is an optimization companion on the half-MBB beam (60 by 20 domain; mesh resolution 1.0; maximum 200 steps; volume budget 0.5); it does not launch the transfer-curve experiment.

How the function computes
Plot actual schedule values at completed-iteration boundaries. Compare to an independent clock/event simulation.

Mathematics

Hold, interpolate linearly, and remain at the final value.

Symbols and units
k: completed iterations; p0/p1: start/end; a: initial hold; n: ramp duration; clip: restrict to [0,1]. Superscript T denotes transpose where used.

Research target
Toporia engineering rule; no direct research figure.

What is compared
The report separates independent numerical checks, equation/curve agreement, paper-visual comparison and unresolved reproduction. Diagnostic success alone never sets a paper match.

Limitations
This function has no claimed originating paper. A parameter-history demonstration is not a research-figure reproduction.

Reproduce
python -m experiments.research_batch2 --case schedule_linear
