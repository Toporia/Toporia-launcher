Research: Local stress penalties and multiplier fields

Question
What does Local stress penalties and multiplier fields compute, and what evidence supports its current implementation?

Setup
GUI Run is a bounded companion, not an assertion of paper reproduction. Domain 60.0 by 20.0 by 0.0; mesh resolution 0.4; volume budget 0.5; method q4+augmented_lagrangian; cap 60; tol=0. Objective {'type': 'compliance'}; constraints [{'type': 'local_stress', 'limit': 3.0}]; parameters {}; filters [{'type': 'density'}]. The saved report records the complete scenario, resolved defaults, physical field and fresh metrics.

How the function computes
Visualizes the existing relaxed-stress field and penalty diagnostics with the dedicated AL updater.

Mathematics

Density relaxation and optional void slack define each local inequality.

The response returns an augmented-Lagrangian penalty, not an ordinary normalized inequality; the matching updater owns multiplier updates.

Symbols and units
lambda_e: local multipliers; mu: penalty; epsilon: void slack; q: stress relaxation; sigma*: limit.

Research target
PolyStress local-stress example: source polygonal mesh/relaxation/panel pending.

What is compared
Independent analytic, assembly, gradient and file/metric checks are separate from source-figure reproduction. Histories, fresh final responses and feasibility are recorded without treating a bounded run as convergence.

Limitations
The Q4 density-relaxed variant is not a PolyStress port. Finite penalties and a bounded solve do not certify local feasibility.
