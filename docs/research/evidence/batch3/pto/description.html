Research: PTO sensitivity-proxy variant

Question
How does PTO sensitivity-proxy variant turn a design and sensitivities into the next material field?

Setup
GUI Run is a bounded optimization companion, not a claimed paper reproduction. Half-MBB domain 60 by 20 mm, mesh 30 by 10, fraction 0.5, E0=1, Emin=1e-9, nu=0.3, top-left downward unit load, left horizontal symmetry and bottom-right vertical roller. Method q4+pto; cap 120; tol=0 (cap or optimizer's own stop). Representation {'type': 'element_density'}; parameters {}; constraints []; filters [{'type': 'density', 'rmin': 1.5}]. Full numerical evidence is separate from this recipe.

How the function computes
Allocates material in proportion to a filtered sensitivity proxy; demonstrates the existing variant without changing it.

Mathematics

A scalar allocation factor a is bisected on actual volume. This code uses negative sensitivity as its energy proxy.

Symbols and units
z: design variables; rho: physical element density; C or f: objective; g: normalized inequality, feasible when <=0; J: Jacobian; superscript T: transpose; plus: next iterate; ell/h: move-and-box bounds. K: stiffness; u: displacement; F: applied load; N: cell count. Coordinates use the scenario's mm units; density is dimensionless. s: allocation weight; q: exponent; gamma: relaxation; a: allocation factor; m: move limit.

Research target
Biyikli-To (2015), Figure 3 MBB PTOc panel (120 by 40, fraction 0.35).

What is compared
The experiment records initial/final fields, pre-update objective histories, fresh final compliance, actual physical volume and solve counts. Independent operator checks and source reviews are reported separately. All unmatched paper figures remain in to-fix.

Limitations
The published PTOc uses element compliance allocation; a negative filtered sensitivity is not proportional to it across varying density. Current q=3/relax=0.2 also differs from the source study. No source replication claimed.
