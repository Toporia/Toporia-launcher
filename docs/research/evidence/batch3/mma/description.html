Research: MMA: local one-budget variant

Question
How does MMA: local one-budget variant turn a design and sensitivities into the next material field?

Setup
GUI Run is a bounded optimization companion, not a claimed paper reproduction. Half-MBB domain 60 by 20 mm, mesh 30 by 10, fraction 0.5, E0=1, Emin=1e-9, nu=0.3, top-left downward unit load, left horizontal symmetry and bottom-right vertical roller. Method q4+mma; cap 120; tol=0 (cap or optimizer's own stop). Representation {'type': 'element_density'}; parameters {}; constraints []; filters [{'type': 'density', 'rmin': 1.5}]. Full numerical evidence is separate from this recipe.

How the function computes
Calls the existing updater through the same Q4 model. Histories record objective evaluations as well as accepted/displayed steps; GCMMA can evaluate multiple trial designs.

Mathematics

MMA builds a separable convex reciprocal approximation between moving asymptotes; nonnegative coefficients match local derivatives.

A dual/subproblem solve proposes the next bounded design. The local one-budget variant and external multi-constraint implementations are distinct.

Symbols and units
z: design variables; rho: physical element density; C or f: objective; g: normalized inequality, feasible when <=0; J: Jacobian; superscript T: transpose; plus: next iterate; ell/h: move-and-box bounds. K: stiffness; u: displacement; F: applied load; N: cell count. Coordinates use the scenario's mm units; density is dimensionless. L/U: asymptotes; p/q: reciprocal coefficients; r: value offset.

Research target
Svanberg MMA/GCMMA numerical examples: numbered panel and original problem inputs still to recover.

What is compared
The experiment records initial/final fields, pre-update objective histories, fresh final compliance, actual physical volume and solve counts. Independent operator checks and source reviews are reported separately. All unmatched paper figures remain in to-fix.

Limitations
The common MBB diagnostic is not a Svanberg paper figure. Library algorithms, scaling, safeguards and stopping rules differ; matching final compliance alone would not establish algorithm equivalence.
