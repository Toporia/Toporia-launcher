Force Inverter

Question
A square mechanism held at the two left corners: a rightward input force should move the right output port leftward. Ground springs represent both ports.

How the function computes
Optimizes the existing own force inverter. A separate fixed-density reciprocity check swaps input and output load vectors in the same spring-stiffness system. The associated research demonstration uses separately declared settings; selecting this preset does not silently substitute that experiment.

Mathematics

Ground springs represent input/output ports; minimizing the signed negative output maximizes motion in the requested direction.

The signed port objective requires a separate adjoint, unlike self-adjoint compliance.

The representation and configured filters map variables to the physical field; their adjoints carry sensitivities back.

Symbols and units
K_s: density-independent port springs; l: output-direction selector; a: adjoint. rho: physical density; z: design variables; R/P: representation/filter maps; J: selected scalar objective; J_R/J_P: Jacobians; superscript T: transpose. In the variant expression a is sharpness, s the frozen scale and i a variant. The displayed equations describe the core model; the exact objective/constraints/filter settings are stated above and explained by their own help topics.
